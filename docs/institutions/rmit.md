# RMIT University

Permissions and access instructions for RMIT-managed computers.

---

## Windows

### Request WSL2

WSL2 needs to be enabled by an administrator. Submit a software request to RMIT ICT.

**Step 1:** Go to the [RMIT IT Software Request form](https://rmititsm.service-now.com/sp?id=sc_cat_item&sys_id=41b97ff5db726110d8257b53f39619d0).

**Step 2:** Fill in:

| Field | What to enter |
|-------|--------------|
| **Request for** | Your name |
| **Email** | Your RMIT email |
| **Software Type** | Desktop |
| **Name of the software** | `wsl2 - windows subsystem for linux` |
| **Publisher/Developer** | `Microsoft` |
| **Number of licenses** | `1` |
| **Reason this software is required** | `Research` |
| **Your asset number** | The red barcode number on your PC |
| **Is there funding allocated?** | No |
| **Preferred contact method** | Email |
| **Version required** | `2` |
| **Operating system** | `Windows` |
| **Work area** | `STEM College - Health and Biomedical Sciences` |
| **Additional information** | `I need admin to run the command wsl --install -d Ubuntu. This is Microsoft approved. See ticket RITM1450733 for more details` |

**Step 3:** Tick the confirmation box and click **Submit**.

**Step 4:** Once you receive your ticket number, [book an ICT support session](https://shorturl.at/ehkov). ICT will run the install on your machine (~5 minutes).

### Request Elevated Rights (for Claude Desktop)

If you want to install Claude Desktop (the GUI app), you need temporary elevated rights.

**Step 1:** Go to the [RMIT Elevated Rights form](https://rmititsm.service-now.com/sp?id=sc_cat_item&sys_id=09bc9b90db3ae150d8257b53f39619c5).

**Step 2:** Fill in:

| Field | What to enter |
|-------|--------------|
| **Request for** | Your name |
| **Email** | Your RMIT email |
| **Preferred contact method** | Email |
| **I need elevated rights to** | `Install Claude Desktop (by Anthropic) from https://claude.ai/download. This is a legitimate AI research tool published by Anthropic. It is needed for the RMIT Psychology AI Research Workshops.` |

**Step 3:** Accept the terms and click **Submit**.

!!! tip "Submit both at once"
    You can submit the WSL2 request and the Elevated Rights request at the same time. They're processed as separate tickets.

## Mac

You should already have admin rights on your RMIT Mac. If you don't, contact RMIT ICT to request them.

Once you have admin rights, go straight to the [Core Stack](../toolkit/core-stack.md) setup.
