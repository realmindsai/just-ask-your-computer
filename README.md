# Just Ask Your Computer

Install a few tools. Ask your computer a question. Watch it answer.

A public setup guide for researchers and professionals who want to use AI CLI tools (Claude Code, Gemini CLI, Codex) on their computers.

**Live site:** [realmindsai.github.io/just-ask-your-computer](https://realmindsai.github.io/just-ask-your-computer)

## What's here

- **Getting Started** — Open a terminal on Mac or set up WSL2 on Windows
- **The Toolkit** — Six core tools (git, Volta, Node.js, uv, Python, Claude Code) plus optional AI assistants and recommended extras
- **Institution Guides** — Permissions and access instructions for managed work computers (RMIT, La Trobe)

## Development

```bash
uv run mkdocs serve
```

Opens a local preview at `http://127.0.0.1:8000`.

## Deployment

Push to `main` — GitHub Actions builds and deploys to GitHub Pages automatically.
